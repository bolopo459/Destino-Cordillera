## Descripción del Proyecto
Plataforma web de promoción turística para la comuna ficticia Destino Cordillera. El sitio ofrece información sobre actividades al aire libre, rutas y panoramas, opciones de alojamiento y gastronomía típica, además de un canal de contacto y reservas para los visitantes.

## Instrucciones para Ejecutar o Visualizar el Sitio
Para visualizar el proyecto localmente sin necesidad de instalar dependencias adicionales:

1. **Clonar o descargar el repositorio:**
   * Mediante Git:
     ```bash
     git clone [https://github.com/bolopo459/Destino-Cordillera.git](https://github.com/bolopo459/Destino-Cordillera.git)
     ```
   * O descargar como archivo comprimido (`.zip`) desde el botón `<> Code` > `Download ZIP` y descomprimir en el equipo.
2. **Abrir el sitio:**
   * Entrar en la carpeta raíz del proyecto.
   * Abrir el archivo `index.html` haciendo doble clic o arrastrándolo a cualquier navegador web moderno (Google Chrome, Firefox, Edge, Safari).
   * Navegar entre las distintas páginas utilizando la barra de menú superior.

## Estructura del Sitio
* `index.html`: Página principal con presentación del destino, imagen destacada y accesos clave.
* `pagina1.html`: Sección de **Panoramas** con al menos 6 actividades, rutas o excursiones organizadas en tarjetas.
* `pagina2.html`: Sección de **Alojamiento y Gastronomía** con opciones de hospedaje y locales gastronómicos.
* `pagina3.html`: Formulario de **Reserva y Contacto**, datos de atención y ubicación referencial.
* `css/styles.css`: Hoja de estilos CSS externa y propia.
* `img/`: Recursos gráficos, iconos e imágenes del sitio.

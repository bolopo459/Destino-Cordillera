## Descripción del Proyecto
Plataforma web de promoción turística para la comuna ficticia Destino Cordillera. El sitio ofrece información sobre actividades al aire libre, rutas y panoramas, opciones de alojamiento y gastronomía típica, además de un canal de contacto y reservas para los visitantes.

## Estructura del Sitio
* `index.html`: Página principal con presentación del destino, imagen destacada y accesos clave.
* `panoramas.html`: Sección de **Panoramas** con al menos 6 actividades, rutas o excursiones organizadas en tarjetas.
* `alojamiento-gastronomia.html`: Sección de **Alojamiento y Gastronomía** con opciones de hospedaje y locales gastronómicos.
* `contacto.html`: Formulario de **Reserva y Contacto**, datos de atención y ubicación referencial.
* `css/styles.css`: Hoja de estilos CSS externa y propia.
* `img/`: Recursos gráficos, iconos e imágenes del sitio.

#Integrantes:

# Tecnologías Utilizadas: 
HTML5
CSS3
Bootstrap 5

#estructura
`index.html`: Página principal con presentación del destino, imagen destacada y accesos clave.
* `pagina1.html`: Sección de **Panoramas** con al menos 6 actividades, rutas o excursiones organizadas en tarjetas.
* `pagina2.html`: Sección de **Alojamiento y Gastronomía** con opciones de hospedaje y locales gastronómicos.
* `pagina3.html`: Formulario de **Reserva y Contacto**, datos de atención y ubicación referencial.
* `css/styles.css`: Hoja de estilos CSS externa y propia.
* `img/`: Recursos gráficos, iconos e imágenes del sitio.
